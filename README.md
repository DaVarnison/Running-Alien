# Running Alien

An endless-runner game you play in a browser. You're an alien sprinting
through an Area 51 base at night, chased by agents.

## Play

Open `index.html` in any browser, or host the file on any static site
and open the page. No build step and no install.

## Controls

- Swipe left / right, or use the arrow keys, to switch lanes
- Swipe up or press Up / Space to jump barriers and crates
- Swipe down or press Down to slide under laser gates
- Grab the glowing energy cells for bonus points
- One stumble brings the agents onto your heels; a second one ends the run

## About

Built with Muse as a Space. This repository holds the standalone
browser version of the game (a single self-contained page plus this
README) so the code can be pulled down, shared, or wrapped for an
app store later.
